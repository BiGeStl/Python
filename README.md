# 🐍 Python Projects

Этот репозиторий содержит мои проекты и практику по Python.
Я изучаю разработку, алгоритмы и постепенно собираю портфолио.

## 📁 Структура

* **basics/** — базовые задачи (условия, циклы, ввод/вывод)
* **algorithms/** — алгоритмы и работа с числами
* **mini-projects/** — небольшие проекты:

  * 🎯 Угадай число
  * 🐉 Игра с драконом
  * 🪙 Симуляция подбрасывания монеты
* **utils/** — вспомогательные функции
